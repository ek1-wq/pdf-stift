PDF-Stift – Quick guide

What's there and where to find it. PC = Windows app and browser, Tablet = Android app. Menu paths refer to the Windows app; in the browser almost everything is in the ⋯ menu at the top right.This edition runs entirely on your PC; your PDFs stay in a normal folder on your computer.

Opening & Library

  • Open a PDF: tap it in the Library · Ctrl+O uploads a fileopens a file
  • Library folder: your PDFs are normal files in Documents\PDF-Stift · open: Help → Open library folder · change: Help → Change library folder… (or Settings → Library)
  • Drag in from Explorer – Word, PowerPoint and Excel files too (converted to PDF). They land in the folder “Documents” (changeable: File → Settings) PC
  • Right-click in Explorer → “Open in PDF-Stift” (Windows 11: “Show more options”) or “Send to → PDF-Stift” PC
  • Print from Word, Chrome, Outlook … to the printer “PDF-Stift” (set up once: File → Set up as printer) PC
  • Watched folder: everything in it is imported automatically (File → Settings) PC
  • Recently opened: right-click the PDF-Stift icon in the taskbar PC
  • Share → PDF-Stift from other apps Tablet

Writing & Highlighting

  • Pen, Highlighter, Highlight text, Shapes, Text box, Lasso, Eraser – toolbar at the top
  • Tool keys: V Select · H Hand · P Pen · M Highlighter · U Highlight text · T Text box · E Eraser PC
  • Hold the space bar = Hand (pan) · middle mouse button does the same PC
  • Right-click selected text: highlight, underline, strike through, copy PC
  • Undo Ctrl+Z · Redo Ctrl+Y (browser: Ctrl+⇧+Z)
  • Notes are saved instantly and synced between PC and tablet – directly in the library folder on your PC

Comments (sticky notes)

  • Choose the “Comment” tool, tap the page, write, “Done”
  • Tap a note = read, edit, delete
  • List of all comments: “Comments” button at the top PC · ⋮ → Comments (list) Tablet
  • When saving/sharing they become real PDF comments (also visible in other PDF programs)

View

  • Whole page Ctrl+0 · 100 % Ctrl+1 · Page width Ctrl+2 · Zoom Ctrl++/−
  • Two pages side by side (also with separate cover page): View menu PC · ⋮ Tablet
  • Rotate view (PDF stays unchanged): Ctrl+⇧++/−
  • Page thumbnails: “Pages” button · hide bars Ctrl+H · full screen F11
  • Presentation with Laser pointer: Ctrl+L · Live view for students via QR code
  • Tabs: next Ctrl+Tab · close Ctrl+W

Search

  • In the PDF: Ctrl+F · next F3 · previous ⇧+F3
  • In all PDFs: search box in the Library (full-text search)
  • Starred: ☆ on a page – in the Library under “★ Starred”

Scans & Text recognition (OCR)

  • Scans are made searchable automatically – in the background, you can keep working
  • “OCR” indicator at the top right: grey = ready · flickering = recognizing · empty circle = automatic off. Tap it: progress, pause, automatic on/off, “Recognize this PDF now”
  • Clean up scans (Tools): straighten skewed pages, remove blank pages, increase contrast
  • In the Windows app the built-in Windows recognition reads the text – much faster

Tools

“Tools” button at the top · Tools menu PC · ⋮ → Tools Tablet

  • Create PDF · Combine · Organize pages (rotate, delete, move, extract, split)
  • Edit text · Edit images · Export (Word, Excel, PowerPoint, images)
  • Header/footer, page numbers, watermark · Bookmarks · Stamps
  • Handouts: 2–9 slides per page, optionally with note lines (new PDF in the same folder)
  • Compare (with an earlier version or another PDF)
  • Fill & Sign · Prepare form · Protect with password

Redact

  • Redact: drag over areas, “Apply redactions” – the content underneath is permanently gone
  • Find and redact: enter names or let it find them automatically (email, phone, IBAN, student ID number, date), review, apply
  • Old unredacted versions are deleted (can be turned off: Settings)

Saving & Sharing

  • Save PDF with notes: Ctrl+S – opens “Save as” PC
  • Drag out: drag a tab or a PDF from the Library to the desktop, into a folder or into an Outlook email – with notes PC
  • Print: Ctrl+P · Share with notes: ⋮ → Share Tablet
  • View and restore earlier versions: Tools → Compare → “With an earlier version”

Settings

  • File → Settings · Ctrl+, PC · ⋮ → Settings Tablet
  • Page display, start tool, print quality, automatic text recognition, redaction, earlier versions, target folder, watched folder, usage log, library folder (Settings → Library)

Updates & Backup

  • “Update available” (blue) = new Windows app · “Server update” (green) = new server version – click either one, then “Install”
  • “Update available” (blue) appears as soon as a new version is out on GitHub – click it, then “Install”
  • Check yourself: Help → Check for updates
  • Tablet: ⋮ → Update app
  • Backup: every night to Nextcloud. Library → “Device & backup” → Check backup / Restore
  • Yellow notice “⚠ Backup” at the top = backup is stuck – tap it
  • Backup: your PDFs are normal files in the library folder – include this folder in your usual backup (Help → Open library folder)
